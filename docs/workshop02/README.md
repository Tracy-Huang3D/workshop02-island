# Workshop 02 学员教程入口

## 从一个模型出发，搭建自己的 3D 小岛

1. [完整教程](./Workshop02_完整教程.md)：跟做正文，覆盖 Step 00–10。
2. [提示词合集](./Workshop02_提示词合集.md)：按步骤复制提示词。
3. [通用 Prompt 模板](./Workshop02_通用Prompt模板.md)：替换成自己的主角、场景和周边资产。

## 准备事项

- Workshop 01 主模型，或本项目提供的芽芽模型。
- Node.js、npm 和支持 WebGL 的浏览器。
- 如需制作自己的素材，准备图像工具与 Tripo 网页端账号。

在项目根目录运行 `npm ci`、`npm run dev`，打开终端显示的地址。代码位于 `src/`，运行模型位于 `public/models/`，配图和 GIF 位于 `docs/evidence/`。

仓库是完成后的示例；直接查看无需重复执行制作提示词。跟做时在自己的项目副本中操作。提示词中的个人进度记录与资产清单由你按实际过程创建，不是本仓库提供的内部制作记录。

本节不要求角色移动、点击收集、声音、复杂动画或公开部署。
