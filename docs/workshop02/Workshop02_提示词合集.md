# Workshop 02 提示词合集

使用方法：复制对应区块，把花括号内容替换为自己的主题。提示词中的“图像工具”“Tripo”“Codex”是使用位置，不要把给图像工具的提示词直接贴到 Codex。

如果你不想只沿用“芽芽的林间秘密花园”，请使用[通用 Prompt 模板](./Workshop02_通用Prompt模板.md)。它按 Step 01–10 提供了可替换主角、场景、物件和视觉风格的完整指令；本文件保留较短的案例速查版。

## Step 01｜创作卡（给 Codex，规划）

```text
主角设定：{角色名字、外形、性格、习惯}。
请帮我把设定拆成一个小型 3D 场景的空间需求：承载地面、遮蔽物、休息处、生活物件、路径和氛围。最多列出 3 个基础周边资产，其他内容标为可选。不要写代码，不要假设我已经有任何 GLB。
```

## Step 02｜概念图（给图像工具）

完整案例提示词见学生正文 Step 02。替换模板：

```text
为原创角色“{角色名}”设计一张“{场景名}”3D 场景概念图。保留{角色外形和关键配饰}，不改变角色设计。场景是一块{地面形态}；{遮蔽物}在{位置}；{休息处}在{位置}；{生活物件}在{位置}；{路径}从{起点}通向{终点}。主角放在{主角位置}，脸部、四肢和关键轮廓清楚可见。保留中央空地，风格为{风格}，主色为{颜色}，使用{光线}。使用{镜头}，所有主要物件完整入镜，背景简洁，不要文字、界面或水印。
```

## Step 03｜素材核对（给 Codex，只读）

```text
请检查当前项目真实存在的文件，按“图片参考 / 原始 GLB / public/models 网页模型 / 代码几何”分别列出资产。逐项写用途、相对路径、文件大小和来源；不要根据文件名猜内容，也不要把 PNG 当成模型。指出缺失项和待确认来源，不修改文件。
```

## Step 04｜独立参考图（给图像工具）

```text
从概念图中提取一个独立的{对象名称}建模参考图。只保留{必须保留的轮廓、材质、颜色和功能结构}；补全被场景物件遮挡的轮廓。去除角色、其他物件、文字、水印和场景背景。保持{统一风格}，使用三分之四视角，完整物体入镜，浅色简洁背景，不要求透明背景或三视图。
```

## Step 05｜生成模型（给 Tripo）

```text
输入是一张独立对象参考图。请生成与参考图一致的精致卡通 3D 模型：保留整体轮廓、材质边界、主要颜色和功能开口；不要加入角色、底座文字或额外物件。模型需要从正面、背面和侧面都完整，底部可落地，适合导出 GLB 并在网页中独立缩放、旋转和移动。
```

## Step 06｜交接资产（给 Codex，只读）

```text
请先核对 workshop2 当前目录和子目录：列出真实存在的参考图片、原始 GLB、public/models 中的网页模型和优化副本。记录准确相对路径、文件大小、用途和原文件→稳定网页文件的复制关系。检查文件名是否有前后空格。保留原始素材，不重命名原文件，不把 PNG 当成已完成 GLB。
```

## Step 07｜基础空间（给 Codex）

```text
请在当前 Vite + Three.js 项目中先搭建基础空间，不加载任何 GLB。创建低矮、边缘圆润的不规则草地小岛：顶面鼠尾草绿色，侧缘暖土色；浅奶油色背景；柔和午后方向光、半球补光和基础阴影；略微俯视的斜前方相机，完整展示小岛。用临时几何和标签标记主角前方中央、遮蔽物左后方、休息处右后方和其他生活物件位置。保留鼠标拖动环绕、滚轮缩放、重置视角和窗口自适应。不要加载真实模型。
```

## Step 08｜分阶段导入（给 Codex）

```text
请阅读 docs/workshop02-progress.md 和当前 src/main.js。每次只处理一个真实 GLB：先请求文件，再显示真实进度或“正在加载”；解析后按实际包围盒等比缩放、调整方向和位置；确认成功后才移除对应占位。失败时显示文件路径与错误并保留回退形状。保留原材质和贴图，不统一覆盖颜色。处理顺序为主角、核心周边、可选装饰；每一步记录路径、缩放、旋转、位置、验证结果和未测试项。
```

## Step 09｜布局反馈（给 Codex）

```text
先阅读 docs/workshop02-progress.md，确认当前实际完成状态。只调整布局，不新增资产、不改模型外观、不改观察功能。将路径排成轻微弯曲并通向休息处；让遮蔽物为休息区提供遮蔽，同时保持主角脸、耳朵和尾巴清楚可见；生活物件形成一个小区域，中央留空。保存同一相机视角的修改前后截图，并从侧面检查接地和穿插。
```

## Step 10｜收尾验证（给 Codex）

```text
请完成 Workshop 02 收尾检查：阅读当前代码和进度文档；不要重复优化已完成模型。停止并重新启动本地服务，验证所有独立 GLB、环绕、缩放、重置和刷新加载；运行 npm run build。分别记录代码存在、构建通过、浏览器可见、控制台错误和未测试项。清理过时成功状态文字，但保留历史阶段占位说明。更新 docs/workshop02-progress.md，不部署、不新增互动。
```
